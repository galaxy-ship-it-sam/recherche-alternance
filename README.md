# Recherche Alternance

Projet personnel de recherche d'alternances en informatique et développement web, principalement dans le Val-de-Marne (94) et à Paris.

## Objectif

Faciliter la recherche d'offres d'alternance et l'identification d'entreprises à contacter pour des candidatures spontanées.

## Fonctionnement prévu

- Rechercher les offres publiées via l'API France Travail, sous réserve d'un accès autorisé.
- Identifier des entreprises via l'API publique Recherche Entreprises.
- Exporter les résultats dans un classeur Excel, avec une feuille pour les offres et une autre pour les entreprises à contacter.
- Lancer la recherche localement sur Windows, manuellement ou selon une programmation horaire.

## État du projet

Prototype Python local. L'accès aux offres France Travail nécessite des identifiants API et l'autorisation appropriée. Le projet n'est pas un site web public et cette page ne diffuse pas de données de l'API.

## Confidentialité

Ne jamais publier les clés API, les secrets d'accès, les fichiers de configuration contenant des identifiants ni les données personnelles.
